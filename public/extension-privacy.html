FEDIT 크롬 확장 개인정보처리방침

시행일 2026년 10월 18일 · 운영 FEDIT(미피 MIFY)
FEDIT 크롬 확장 프로그램(이하 “확장”)은 사용자가 보고 있는 쇼핑몰 상품을 FEDIT으로 가져와 AI로 분석하고, 사용자의 FEDIT ‘내 보드’에 저장하는 도구입니다. 확장은 이 기능에 필요한 정보만 다루며, 사용자가 방문한 사이트 기록을 모으거나 광고에 쓰지 않고, 정보를 판매하지 않습니다.

1. 확장이 다루는 정보

상품 페이지 정보 사이드패널이 열려 있는 동안 사용자가 보고 있는 탭의 상품 정보 — 페이지 주소(URL), 상품명, 브랜드, 쇼핑몰 이름, 카테고리, 대표 이미지 주소, 상품 설명, 색상, 가격. 페이지에 공개된 상품 정보(구조화 데이터·메타 태그)에서만 읽으며, 입력란·결제 정보·쿠키 등은 읽지 않습니다.
로그인 정보 FEDIT 웹사이트(fedit.mify.im)에 로그인하면 발급되는 로그인 토큰. 웹사이트와 같은 계정으로 확장을 쓰기 위해 사용합니다. 비밀번호는 확장이 다루지 않습니다.
계정 이용 정보 보드 목록, 마지막으로 고른 보드, 이번 달 AI 분석 사용 횟수(요금제별 한도 계산용).

2. 언제 읽고, 언제 보내나요

  • 사이드패널이 열려 있을 때만 지금 보고 있는 탭의 상품 정보를 읽어 패널에 보여줍니다(탭을 바꾸면 그 탭을 다시 읽습니다). 이때 읽은 정보는 사용자의 브라우저 안에만 있습니다.
  • 사용자가 “AI로 분석하기”를 누르면 그 상품의 정보(1번의 상품 페이지 정보)가 FEDIT 서버로 전송되어 AI 분석에 쓰입니다.
  • 사용자가 “내 보드에 저장”을 누르면 그 상품이 사용자 계정의 보드에 저장됩니다.
  • 패널이 닫혀 있을 때, 보고 있지 않은 탭, 방문 기록은 읽거나 보내지 않습니다.

3. 이용 목적

  • 상품 이미지·정보의 AI 분석(유형, 소재, 색상, 핏, 무드 등)과 결과 표시
  • FEDIT 데이터베이스 속 비슷한 상품 추천
  • 사용자 보드에 상품 저장
  • 요금제별 월 분석 한도 확인

4. 저장 위치와 보관 기간

  • 브라우저(확장 저장소): 로그인 토큰과 마지막으로 고른 보드 번호를 chrome.storage.local에 저장합니다. 로그아웃하거나 확장을 삭제하면 지워집니다.
  • FEDIT 서버: 분석을 요청한 상품의 정보와 분석 결과, 분석 사용 기록, 보드에 저장한 상품을 보관합니다. 보드 항목은 사용자가 삭제하거나 회원 탈퇴할 때까지, 분석 사용 기록은 요금 한도 계산과 부정 이용 방지를 위해 필요한 기간 동안 보관합니다.
  • 상품 분석 결과는 상품 자체에 대한 정보이므로, 같은 상품을 다른 사용자가 분석할 때 다시 쓰일 수 있습니다. 이때 누가 분석을 요청했는지는 다른 사용자에게 공개되지 않습니다.

5. 제3자 제공

확장이 다루는 정보는 FEDIT 서비스 제공 목적으로만 쓰며, 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 법령에 따라 요구되는 경우는 예외로 합니다.

6. 크롬 웹스토어 사용자 데이터 정책 준수

FEDIT 크롬 확장이 크롬 API로 받은 정보의 사용과 다른 앱으로의 전송은 Chrome 웹스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

7. 사용자의 권리

  • 보드에 저장한 상품은 FEDIT 웹사이트의 ‘내 보드’에서 언제든 삭제할 수 있습니다.
  • 확장을 삭제하면 브라우저에 저장된 확장 데이터가 모두 지워집니다.
  • 계정·데이터 삭제, 열람 요청은 아래 연락처로 보내주세요.
